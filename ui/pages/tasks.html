Task manager

Task Type Memory Working set Private CPU Network Pending PID

Memory is the engine's private footprint of the process; working set and private bytes come from Windows. CPU is the share of all processors. Network counts what the tabs of a renderer received since the previous second. Pending is the number of requests its tabs wait for, with the age of the oldest once that is over five seconds (an open stream counts, a page that never finishes loading shows here). Ending a renderer shows its tabs the "page crashed" message; the browser process cannot be ended here. Refreshes every second (Shift+Esc opens this page).
