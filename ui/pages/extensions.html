Extensions

Krunk runs its own subset of Manifest V3: content scripts in an isolated world of web pages, a background page, the toolbar button with its popup, options pages, chrome.runtime, storage, tabs, action, alarms, i18n, scripting and static declarativeNetRequest rules. Blocking webRequest, debugger, native messaging and dynamic rules are never provided. Extensions never run on Krunk's own pages, and not in private tabs unless you allow it.
