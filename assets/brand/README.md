# Brand art

- `krunk.svg`: the Krunk product icon (source of `krunk.ico`, `krunk-64/256.png` and the website's
  icons via `make-icons.sh`; the engine's product logo via `scripts/cef-build/cross-build.sh brand`;
  drawn again by hand as the Android launcher icon and TV banner in `android/`). Since 2026-11-24 it
  is in the KruxSYS family: KruxSYS's dark square and cyan corner brackets, Krunk's "K" in light
  grey with its offset lower arm in Krunk's orange-to-magenta. The earlier icon (orange-to-magenta
  rounded square, white K) is in git history; https://kruxsys.com/projects/krunk/ still showed it
  on 2026-11-24 (KruxSYS's site has to update its copy).
- `kruxsys.svg`: the KruxSYS publisher mark, downloaded unchanged on 2026-11-24 from
  https://kruxsys.com/assets/brand/logo.ce36e02f37.svg. The website serves a copy as `/kruxsys.svg`.
- `installer-side.svg` → `installer-side.bmp` (164×314, the installer's welcome/finish image, in the
  KruxSYS look); rendered by `make-icons.sh`.

Krunk is a KruxSYS project (https://kruxsys.com/).
