Krunk's built-in new tab page wallpapers (0.7.0)
=================================================

All ten were made for Krunk; none is a third-party image. assets/wallpapers/make.py turns them
into ui/shared/wallpapers/*.webp (2048x1152, plus 320 px thumbnails; 1.3 MB in all).

Generated with the z-image-turbo text-to-image model (z-image-turbo-fp8-e4m3fn_flux,
2048x1152, on the project's SwarmUI server). The PNG originals are not kept in git
(assets/wallpapers/originals/, ignored): to regenerate one, run the same prompt, size and seed.
